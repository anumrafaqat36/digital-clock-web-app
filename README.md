# ⏰ Smart Digital Clock

A modern and responsive **Smart Digital Clock** built using **HTML, CSS, and JavaScript**. This project includes a live digital clock, stopwatch, countdown timer, smart alarm with multiple sounds, theme switcher, and a 12/24-hour format toggle.

## ✨ Features

- 🕒 Live Digital Clock
- 📅 Current Date Display
- 🌙 12-Hour / 24-Hour Format
- 🎨 Multiple Color Themes
- ⏱ Stopwatch
- ⏲ Countdown Timer
- ⏰ Smart Alarm
- 🎵 Multiple Alarm Sounds
- ▶️ Preview Alarm Sound
- 😴 Snooze Feature
- 🔕 Stop Alarm
- ✨ Animated Background
- 📱 Responsive Design
- 💾 Theme Preference Saved

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
